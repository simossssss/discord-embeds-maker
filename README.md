This project is an embed maker bot for announcements.
it is simple to run: 
* firstly put your bot token in the bot_token file 
* then in the main.py add the channel id you wan to have your announcements on (the channel id must be an intiger not a string!)
* lastly add your announcements by running the embedMaker.py the bot should automatically upload all the pending ones
* note it checks for missing announcements every one minute
